# Задача

Сформируй персональный совет, который помогает пользователю двигаться к его цели.

Пользовательская цель — главный ориентир при выборе рекомендации.

Используй данные сна за сегодня и последние дни, чтобы определить,
какое конкретное действие сейчас наиболее полезно для достижения этой цели.

Контекст базы знаний используй как источник доказательных рекомендаций.

Не давай общий совет только потому, что он связан с целью.
Выбери одно конкретное и выполнимое действие, которое:
- напрямую связано с целью пользователя;
- актуально с учётом текущих данных сна;
- соответствует контексту базы знаний;
- не повторяет предыдущие советы.

Если цель сформулирована широко, не пытайся решить её целиком за один совет.
Выбери один наиболее актуальный шаг на сегодня.

Не утверждай, что действие гарантированно приведёт к достижению цели.
Не придумывай факты о пользователе, которых нет во входных данных.
